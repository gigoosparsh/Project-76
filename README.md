# Project 76

A React Native mobile application built using Expo. The project contains multiple application screens and provides a starting structure for mobile application development.

## Project Overview

Project 76 is a mobile application developed using React Native and Expo. It follows a component-based structure, with separate JavaScript files for different application screens.

## Application Screens

The project currently contains the following screens:

- **Home Screen:** Main application screen.
- **DailyPic Screen:** Screen dedicated to daily pictures.
- **SpaceCraft Screen:** SpaceCraft application screen.
- **StarMap Screen:** StarMap application screen.

Note: These screens currently contain basic placeholder layouts and can be extended with additional functionality.

## Prerequisites

Before running the project, install:

- Node.js
- npm or Yarn
- Expo CLI / Expo development tools
- Visual Studio Code (recommended)

## Installation and Setup

**1. Clone the repository**

```bash
git clone <repository-url>
```

**2. Navigate to the project directory**

```bash
cd Project-76
```

**3. Install dependencies**

Using Yarn:

```bash
yarn install
```

Alternatively, using npm:

```bash
npm install
```

## Running the Application

Start the Expo development server:

```bash
npm start
```

Run on Android:

```bash
npm run android
```

Run on iOS:

```bash
npm run ios
```

Run on Web:

```bash
npm run web
```
